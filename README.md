# DataStructure

A python package implementing common data structures from scratch for learning and practicing

## Features
- Doubly Linked List
- Singly Linked List
- Pythonic implementation
- Iterator support
- Reverse iteration
- Indexing
- Insert
- Delete
- Append
- Remove

## Installation

Clone the repository:

``` bash
git Clone <respository-url>
```
Move into the project:

``` bash
cd datastructures
```

Create a virtual environment:

```bash
python -m venv .venv
```
Activate it.

Windows:
```bash
.venv\Scripts\Activate.ps1
```
Install dependencies

```bash
pip install -r requirements.txt
```

## Running Tests
```bash
python -m pytest tests
```
